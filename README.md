# Janina @ 18 — 18 After Hours

A responsive birthday invitation website made with plain HTML, CSS, and JavaScript for Visual Studio Code.

## Open it
1. Extract `janina18_website.zip`.
2. Open the `janina18_website` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the **Live Server** extension and click **Go Live**.

## Customize
- Edit invitation wording and event details in `index.html`.
- Change colors, fonts, layout, and mobile styling in `style.css`.
- Images are in the `assets` folder. Keep their filenames the same, or update the matching `src`/CSS paths.
- The View Map links open Janina’s supplied Google Maps Street View location.

## Notes
- The website is a single scrolling page styled as distinct invitation sections, so it works well on phones and desktops.
- Some uploaded reference photos weren't included as separate files, so the beauty section uses the available uploaded beauty image(s). Replace any image in `assets` with the exact product photo if you want a more precise match.
